git cheat sheet .txt 

cd = change directory

mkdir = make directory

dir = display directory

/D = change drive

Current_Directory hello.txt = do the hello.txt file

move <file (a)> < destination (b)> = move file from a to b

echo text = print text in console window e.g. text

reset = go to older commit and forget current

show = show current commits

checkout = change branch

init = create new repository
